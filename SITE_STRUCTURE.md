## 📍 File Relationships

```
index.html (Main File)
    ├── Links to: styles.css (Visual Design)
    ├── Links to: script.js (Interactivity)
    ├── Meta tags (for SEO & Social)
    └── Content (from content.md template)
         ├── Hero section copy
         ├── Bio narrative
         ├── Skills list
         ├── Experience entry
         ├── Awards section
         └── Contact methods

styles.css (Design Layer)
    ├── :root variables (Colors, spacing, fonts)
    ├── Base styles (Typography, reset)
    ├── Component styles (.hero, .card, .section)
    ├── Responsive breakpoints (@media queries)
    ├── Dark mode support (@media prefers-color-scheme)
    └── Accessibility features (focus states, motion preferences)

script.js (Interaction Layer)
    ├── Navigation (smooth scroll, active states)
    ├── Animations (fade-in on scroll)
    ├── Contact methods (tracking)
    ├── Analytics hooks
    └── Utility functions
```

## 🎯 User Journey Map

### First-Time Visitor (45 seconds)
```
Landing on site
    ↓
Reads Hero headline (5 sec)
    ↓
Scans About section (10 sec)
    ↓
Glances at Skills (5 sec)
    ↓

    ↓

    ↓
```

## 🎨 Component Library

### Reusable Components

```
1. CARD (.card)
   - Shadow: subtle to medium
   - Border-radius: 8px
   - Hover effect: lift + shadow increase
   - Padding: consistent spacing
   - Used in: Skills, Awards, Contact

2. BUTTON (.button)
   - Primary: Electric Blue bg, white text
   - Secondary: White bg, Navy border
   - Hover: Color invert, slight scale
   - Used in: Hero CTA, Contact links

3. TAG (.tag, .skill-tag, .exp-skill-tag)
   - Light background with text color
   - Small padding
   - Rounded corners
   - Hover: invert colors
   - Used in: Skills, Experience

4. STAT-CARD (.stat-card)
   - Left border accent
   - Icon + text layout
   - Hover: lift effect
   - Used in: About section

5. SECTION (.section)
   - Consistent padding (80px vertical)
   - Max-width container
   - Alternating backgrounds
   - Section title style
   - Used in: All major sections
```

## 🔄 Animation & Interaction Guide

### Hover Effects
```
Links:
  Default → Blue
  Hover → Brighter blue + underline

Buttons:
  Default → Solid color
  Hover → Darker shade + shadow + lift

Cards:
  Default → Flat (shadow-md)
  Hover → Lifted (shadow-lg) + translate(-4px)

Tags:
  Default → Light background
  Hover → Dark background + light text
```

### Scroll Animations
```
On Page Load:
  Hero section → Fade in
  Buttons → Fade in with delay

On Scroll:
  Skill cards → Fade in + slide up
  Award cards → Fade in + slide up
  Experience card → Fade in + slide up
  Stat cards → Fade in + lift
```

### Navigation
```
On Click (nav link):
  Smooth scroll to section
  Active link highlight (blue underline)
  Nav stays sticky at top
```
