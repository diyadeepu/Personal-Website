## 🔄 HOW DARK MODE WORKS

The website **automatically detects** your system preference:

### On macOS:
- System Preferences → General → Appearance
- Choose: Light, Dark, or Auto
- Your website adapts instantly!

### On Windows:
- Settings → Personalization → Colors
- Choose: Light or Dark mode
- Your website adapts instantly!

### On iPhone/iPad:
- Settings → Display & Brightness
- Choose: Light or Dark mode
- Your website looks perfect!

## 🎨 COLOR VARIABLE SYSTEM

All colors use CSS variables, making them easy to customize:

```css
:root {
    --color-bg-primary: #FFFFFF;
    --color-text-primary: #1A202C;
    --color-accent-primary: #3B82F6;
    /* ... more variables ... */
}

@media (prefers-color-scheme: dark) {
    :root {
        --color-bg-primary: #0F172A;
        --color-text-primary: #F1F5F9;
        --color-accent-primary: #60A5FA;
        /* ... dark mode values ... */
    }
}
```

## ✨ MODERN DESIGN FEATURES

### 1. **Professional Color Hierarchy**
- Primary accent: Blue (#3B82F6) for important elements
- Secondary accent: Purple (#8B5CF6) for secondary actions
- Tertiary accent: Cyan (#06B6D4) for additional info

### 2. **Better Shadows**
Light Mode:
- Soft shadows: `0 1px 2px rgba(0, 0, 0, 0.05)`
- Medium shadows: `0 4px 6px rgba(0, 0, 0, 0.07)`
- Strong shadows: `0 10px 15px rgba(0, 0, 0, 0.1)`

Dark Mode:
- More prominent shadows for depth
- Higher opacity for visibility

### 3. **Text Color Strategy**
Three levels of emphasis:
1. **Primary** - Headings, important content
2. **Secondary** - Body text, descriptions
3. **Tertiary** - Labels, metadata, captions
