
## 🔧 TROUBLESHOOTING

### Site looks wrong
→ Clear browser cache (Cmd+Shift+R)
→ Check that all files are in same folder
→ Verify file names have no typos

### Links don't work
→ Test in incognito mode
→ Check email format (mailto:email@domain.com)
→ Verify social URLs are public

### Mobile view broken
→ Test in browser DevTools
→ Check media queries in CSS
→ Verify viewport meta tag in HTML

### Can't deploy
→ Make sure files are saved
→ Check GitHub/Vercel/Netlify setup
→ Verify index.html is in root folder

### Dark mode not working
→ It's automatic (depends on OS settings)
→ Test on macOS/Windows with dark mode on
→ Check browser dev tools
