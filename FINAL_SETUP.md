## 🌙 HOW TO TEST DARK MODE

### On macOS:
```
1. Click Apple menu → System Preferences
2. Select General
3. Choose "Appearance"
4. Select "Dark" mode
5. Refresh website
6. Colors automatically update!
```

### On Windows:
```
1. Settings → Personalization → Colors
2. Choose "Dark" mode
3. Refresh website
4. Colors automatically update!
```

### On iPhone/iPad:
```
1. Settings → Display & Brightness
2. Choose "Dark" mode
3. Open website in Safari
4. Colors automatically update!
```
