## 🔧 IF YOU WANT TO CUSTOMIZE FURTHER

### Change Accent Colors
Edit `styles.css` `:root` section:
```css
:root {
    --color-accent-blue: #0066FF;    /* Change this */
    --color-purple: #8B5CF6;         /* Or this */
    --color-amber: #F59E0B;          /* Or this */
}
```

### Adjust Photo Size
Edit `.profile-photo` in CSS:
```css
.profile-photo {
    width: 250px;      /* Change to 300px for larger */
    height: 250px;
    /* ... rest of style ... */
}
```

### Change Animation Speed
Edit hero background animations:
```css
animation: float 6s ease-in-out infinite;  /* 6s = speed */
```
(Lower = faster, Higher = slower)
